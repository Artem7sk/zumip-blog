AI Prompts for Creating Scenario-Based Quiz Questions for Courses

Сценарные вопросы — один из самых эффективных форматов проверки знаний. Вместо «Что такое X?» вы спрашиваете: «Вы менеджер проекта, клиент требует сократить сроки на 30%. Какое действие будет правильным?» Такие вопросы проверяют не память, а применение навыка — и именно поэтому они так ценны в корпоративном обучении, онлайн-курсах и вузовских программах.

Проблема в том, что писать их вручную долго: нужно придумать реалистичный контекст, правдоподобные дистракторы и корректный фидбек. AI ускоряет этот процесс в разы — если знать, как формулировать промпты. Ниже — рабочая система.

Почему сценарные вопросы работают лучше фактических

Фактические вопросы («Назовите три этапа...») проверяют узнавание. Сценарные — решение задач в условиях неопределённости. Исследования в области instructional design (например, работы по когнитивной нагрузке и situated learning) показывают: перенос знаний в реальную практику лучше формируется, когда обучение приближено к рабочему контексту.

Практические следствия:

    • Студент не может угадать ответ, опираясь на формулировку.
    • Дистракторы отражают типичные ошибки, а не случайный шум.
    • Фидбек можно привязать к последствиям решения, а не к «правильно/неправильно».

Базовая структура сильного сценарного вопроса

Прежде чем писать промпт, зафиксируйте анатомию вопроса. AI будет генерировать именно её.

1. Роль — кем является студент («вы — тимлид», «вы — медсестра в отделении»).

2. Контекст — 1–3 предложения с конкретикой: сроки, ограничения, данные.

3. Триггер — событие, требующее решения («клиент звонит с претензией»).

4. Вопрос — что именно нужно сделать («какой шаг предпринять первым?»).

5. Варианты — 3–5 ответов, из которых один лучший, остальные — правдоподобно неверные.

6. Фидбек — объяснение, почему лучший ответ верен и почему остальные нет.

Если хотя бы один элемент отсутствует, вопрос превращается в абстрактную загадку. AI без вашего указания почти всегда пропускает пункты 2 и 6.

6 рабочих AI-промптов для сценарных вопросов

Ниже — шаблоны, которые можно копировать и адаптировать. Замените текст в квадратных скобках.

1. Промпт «из учебного материала в сценарий»

```

Ты — instructional designer. Ниже — фрагмент учебного материала:

[вставьте текст урока, 200–500 слов]

Создай 3 сценарных вопроса, которые проверяют применение этих знаний.

Требования к каждому вопросу:

    • Роль студента и рабочий контекст (1–2 предложения).
    • Конкретная проблема с ограничениями (сроки, бюджет, данные).
    • 4 варианта ответа: 1 лучший, 3 правдоподобных дистрактора на основе типичных ошибок.
    • Фидбек на 2–3 предложения для каждого варианта.
    • Уровень сложности: [средний / высокий].
```

2. Промпт «дистракторы на основе типичных ошибок»

```

Вот правильный ответ на сценарный вопрос: [ответ].

Сгенерируй 3 неверных варианта, которые:

    • выглядят логично для новичка;
    • отражают конкретные misconceptions: [перечислите 2–3];
    • не являются абсурдными или очевидно неправильными.
Для каждого дистрактора объясни, какую именно ошибку в мышлении он проверяет.

```

3. Промпт «многоуровневый сценарий»

```

Создай сценарный кейс с 3 последовательными вопросами, где ответ на каждый

влияет на следующий шаг. Тема: [тема]. Контекст: [отрасль, роль].

Вопрос 1 — диагностика ситуации.

Вопрос 2 — выбор действия.

Вопрос 3 — оценка последствий.

Для каждого вопроса: 3 варианта ответа и фидбек.

```

4. Промпт «проверка на качество»

```

Проверь сценарный вопрос ниже по чек-листу:

1. Есть ли однозначно лучший ответ?

2. Не подсказывает ли формулировка правильный вариант?

3. Дистракторы правдоподобны?

4. Контекст реалистичен для [аудитория]?

5. Фидбек объясняет, а не просто констатирует?

Выдай список проблем и переписанную версию.

[вставьте вопрос]

```

5. Промпт «адаптация под уровень»

```

Возьми этот сценарный вопрос: [вопрос].

Создай две версии: для новичков (больше подсказок в контексте) и для

опытных (меньше контекста, выше неопределённость). Сохрани тему и

проверяемый навык.

```

6. Промпт «генерация по таксономии Блума»

```

Создай сценарные вопросы по теме [тема] на уровнях:

    • применение (apply),
    • анализ (analyze),
    • оценка (evaluate).
Для каждого — контекст, вопрос, 4 варианта, фидбек.

Укажи, какой уровень таксономии проверяет каждый вопрос.

```

Чек-лист перед публикацией вопроса

Пробегитесь по списку — он экономит часы редактуры:

    • [ ] В сценарии есть роль, контекст и ограничения.
    • [ ] Правильный ответ однозначно лучший, а не «наиболее подходящий из равных».
    • [ ] Дистракторы основаны на реальных ошибках, а не на случайных фактах.
    • [ ] Формулировка не содержит подсказок («всегда», «никогда», «наиболее безопасный»).
    • [ ] Фидбек объясняет причинно-следственную связь.
    • [ ] Длина вариантов примерно одинаковая.
    • [ ] Нет культурных или профессиональных допущений, отсекающих часть аудитории.

Типичные ошибки при работе с AI

Даже с хорошими промптами легко получить мусор. Что чаще всего идёт не так:

AI раздувает контекст. Модель по умолчанию пишет 5 предложений там, где хватит одного. Указывайте лимит слов.

Дистракторы становятся очевидными. Без явного запроса на «правдоподобные misconceptions» AI выдаёт варианты вроде «уволить сотрудника» рядом с «провести встречу».

Фидбек превращается в повтор ответа. Просите объяснять почему, а не что.

Все вопросы получаются одного уровня. Явно указывайте таксономию или сложность.

Теряется связь с материалом курса. Всегда вставляйте фрагмент урока в промпт — иначе AI придумывает факты.
